Verdict: needs-review
Arch:    hopper-only

pass set produce different bits.  Reference = the production sm_90 pipeline
with `coalesce` removed; candidate = the full production

## Pass pipeline: reference vs candidate
Both sides run the real `CUDABackend.make_ttgir` step list for `cuda:90`
(rebuilt step by step in `harness/pipeline.py`).  The candidate runs all of
it.  The reference runs the same list with these steps removed:

```

```

After TTGIR the two sides are byte-identical code paths: both are written to a
`.ttgir` file and handed to `triton.compile`, which skips every stage up to and
including `ttgir`, so `make_llir` / `make_ptx` / `make_cubin` are the same.

They only move data, change layouts, schedule, or lower to hardware, so the per-element arithmetic and its order should be untouched.

## Addendum: PLAN section 4 labels (backfilled 2026-08-17)

Scope reminder: this record says only that two compilations differing in the
pass set produce different bits. It is not a claim of a compiler bug.

```
pass-class:            layout
ndiff/total:           23/64
max_abs_diff:          2048.0
heap-shift-survives:   3/3
int-input-control:     {"exact": "yes", "bound": 65536, "exact_below": 16777216, "holds": true, "why": "acc += v*v with |v| <= 8 gives |acc| <= 64*C, and tl.sum / tl.max over integers are exact", "result": "equal"}
```

**Integer-input control.** With inputs that are integers in `[-8, 8]`, every
fp32 accumulator in family `loop_reduce` stays below `2^24 = 16777216` (bound here:
`65536`, exactness `yes`), so every accumulator add
is exact and summation order cannot change the result.
acc += v*v with |v| <= 8 gives |acc| <= 64*C, and tl.sum / tl.max over integers are exact
Re-running this comparison on integer-valued inputs: **equal**.
So the difference does NOT survive integer-valued inputs, so it is consistent with a reordered floating-point sum.

**Allocator perturbation.** The comparison was repeated 3 times with the GPU
allocator perturbed so the buffers land at different addresses with identical
values; the difference survived 3/3 of them.
